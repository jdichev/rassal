# Agent Guidelines

## Slide Generation

- **Maximum Slide Size**: Ensure that each generated slide does not contain too much text. If a slide's content exceeds a reasonable amount (e.g., more than 5-6 bullet points or a mix of headers, quotes, and points that fill the screen), it MUST be split into multiple slides using the `---` separator.
- **Readability**: Prioritize clarity and visual balance. Each slide should focus on a single core concept or a small group of related points.
